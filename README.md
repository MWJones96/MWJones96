### Hi, I'm Matthew 👋

By day I'm a backend engineer. Most recently I made a simulation platform highly available on Kubernetes, and before that I worked on AWS Inspector and at U.S. Bank.

Outside work I'm usually taking something apart to see how it works. If a tool, a protocol or a piece of old hardware has a spec, I'd rather write my own version than read about it. This profile is where that ends up.

#### What I'm building for fun

- 🎮 **[NESEmulator](https://github.com/MWJones96/NESEmulator)**: a Nintendo Entertainment System in Rust. The 6502 CPU runs every one of its 256 opcodes, including the undocumented ones, cycle-accurate and checked line by line against the `nestest` log. The PPU is clocked 3:1 against the CPU, as on the real thing, and draws scrolled backgrounds. I started with [CHIP-8 in Python](https://github.com/MWJones96/Chip8-Interpreter), which is where I got hooked.
- 🔧 **[coding-challenges](https://github.com/MWJones96/coding-challenges)**: rebuilding Unix tools in Rust. I've done `wc` and a JSON lexer that handles RFC 8259 down to UTF-16 surrogate pairs. There's also an `md5sum` where MD5, SHA-1/256/384/512 and HMAC are all written from scratch, padding included.
- 🎄 **[Advent of Code](https://github.com/MWJones96/Advent-of-Code)**: every December in Rust, reaching for Z3 when a puzzle turns out to be a system of equations. 2026 is scaffolded and waiting for 1 December.
- ⚫ **[RustGo](https://github.com/MWJones96/RustGo)**: the rules of Go, including captures, liberties and ko, as a pure domain core with a Clean Architecture use-case layer.
- ❄️ **[.dotfiles](https://github.com/MWJones96/.dotfiles)**: a single Nix flake that sets up my whole machine on macOS or Linux, from bare metal to my Neovim config, with one script.
